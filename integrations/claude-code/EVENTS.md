# Hook event names

Every structured logger emits `event_name` (canonical namespace) and `event_schema: 2`. The existing `event` field remains unchanged for log consumers. Set `COGNEE_LOG_EVENT_SCHEMA=2` to use canonical names in `event`; the original then appears in `legacy_event`. Consumers should read `event_name` first during migration. Unknown dynamic events receive the logger namespace; CI inventories literal call sites.

Names cover current hooks, configuration, transcript cleanup, and both watchers. Removed client-side bridge hooks are not reintroduced.
