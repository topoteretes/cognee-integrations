# Privacy Policy

## Data Collection

This plugin collects and transmits the following data to the Cognee server you configure (Cognee Cloud or your self-hosted instance):

- **Credentials** (server URL and either an API key or a user email and password) - used solely for authenticating requests to your Cognee instance. The password is only ever sent to the login endpoint of the server you configured.
- **Text data and files** - content you explicitly provide through the Remember, Add Data, Add File and Update Data tools, sent to your Cognee instance for ingestion.
- **Queries, questions and answers** - provided through the Recall, Search and Remember Entry tools, sent to your Cognee instance for processing or storage.
- **Dataset and data identifiers** - used to address datasets and data items on your Cognee instance.

## Data Usage

All data is transmitted directly to the Cognee server at the URL you configure. No data is sent to any other third party by this plugin.

## Data Storage

This plugin does not store any data locally. Credentials are stored by Dify's credential management system. All ingested content, graph data and session memory live on your Cognee instance.
