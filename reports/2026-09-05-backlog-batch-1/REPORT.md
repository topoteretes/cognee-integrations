**Fixes included in this workspace**

- **Prompt latency:** `load_resolved(identity=False)` returns local session fields before identity HTTP probes. Only the prompt's session-ID lookup opts out; callers that need identity preserve existing behavior. Applied to Claude Code and Codex.
- **Watcher credentials:** both SessionStart spawners put the key in the child environment, and both exit watchers read it from there. Tests check the launch arguments and propagation into the final sync.
- **Release metadata:** inventory now agrees with Claude Code **1.4.4**, Codex **1.5.4**, OpenClaw **2026.9.2**, and n8n **0.5.1**. The new [checker](../../scripts/check_version_consistency.py) and [workflow](../../.github/workflows/check-version-consistency.yml) reject drift, missing manifests/marketplace entries, invalid versions, and conflicting duplicate entries. This is a correction to metadata, not a release or version bump.
- **Inventory cleanup:** removed the duplicate Strands row and obsolete pending `claude` row, whose package already lives under `claude-agent-sdk`. The integration code remains in place. Other pending migrations were outside this batch's review.
- **Documentation:** replaced OpenClaw's fixed “14 search types” claim with wording that follows configured server capabilities.

No integration package should be deleted based on this batch. OpenCode has substantial unfinished requirements, but an existing implementation to improve. Remove duplicate tracking and obsolete proposals while preserving maintained packages and contributor attribution.
